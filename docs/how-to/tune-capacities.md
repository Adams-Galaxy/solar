# Tune Capacities

1. count compile-time declarations and registrations;
2. estimate credible concurrent bursts and maximum encoded payloads;
3. enable accounting/history needed to measure high-water use;
4. select explicit overflow and stop behavior;
5. stress the native build above expected load;
6. reduce or increase Kconfig maxima from evidence;
7. verify target RAM, stack, and binary size.

Catalog maxima must fit the effective Blueprint. Runtime depths must fit bursts,
not merely steady-state throughput.
