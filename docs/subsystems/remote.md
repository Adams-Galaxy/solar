# Remote

Remote is a standalone bounded byte-protocol module. IDL-generated schemas,
Data, Actions, and Streams form an `Architecture`; `ByteRuntime` owns its
catalogs, links, sessions, worker, and compile-time scheduler policy.

Generated C++ contribution roles connect handwritten behavior at compile time.
The linked ELF embeds the authoritative manifest. Shipment generation derives
the typed Python application package from that effective image, while
`solar_remote` owns transport and session behavior.

Streams are real stream endpoints. Input groups enforce one source
configuration while each host client independently subscribes to what it
needs. All frames, messages, queues, response caches, credit windows, and
reassembly state are bounded by Kconfig or typed policy.
