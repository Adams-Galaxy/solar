# Documentation Pass

Status: complete

This directory contains execution artifacts for the documentation pass defined
by `../documentation-planning.md`.

- `inventory.md` records the current public surface and source ownership.
- `terminology.md` locks words and capitalization used by public pages.
- `coverage.md` tracks required public and architecture coverage.
- `landed/` records evidence as each documentation stage closes.
- `handoff.md` summarizes the completed product and remaining environmental gates.

These files are development records and are excluded from the public Sphinx
site.
